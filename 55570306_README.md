# Evo X ECU Definition — 55570306

ECUFlash/XML definition work for Mitsubishi Lancer Evolution X ROM ID `55570306`.

This definition is intended for the completed `55570306_FULL_CORRECTED.xml` ROM-definition file and is built around the live `55570306` target image. It is not a calibration/tune file and does not contain flashable tuning changes by itself; it defines how maps, tables, axes, thresholds, scalings, and ROM metadata are exposed in compatible tuning/editing software.

> Note: the completed XML currently identifies as `55570306`, with internal ID bytes `55 57 03 06` at address `0x5002A`. If you intended a separate `55590006` ROM, do not reuse this definition without confirming the internal ROM ID and offsets against that binary.

## Repair Notes

The XML was repaired against the live `55570306` target instead of blindly shifting offsets from another definition. Supplied nested axis definitions were preserved, and downstream map/table/threshold addresses were corrected using live descriptor records, unique target-body matches, and cross-checked ROM-definition families.

Known intentionally cautious behavior:

- Axis definitions supplied with the XML were kept intact.
- Direct tables through `Torque Output / Monitors and Limiters` were preserved, including torque-monitor records.
- Airflow / Adaptive Load Learning, Airflow / Load Calculation, and RAX3 Fast Logging categories were preserved.
- Legacy records without a unique live descriptor or body match remain at their supplied address and should be manually reviewed before tuning.

## Usage

1. Back up the original ROM before making any edits.
2. Verify the ECU internal ROM ID is `55570306` before using this definition.
3. Place the XML definition where your tuning/editor software expects Mitsubishi Evo X XML definitions.
4. Open the matching ROM with the definition loaded.
5. Review critical maps before editing or flashing, especially any table marked for manual review or inherited from legacy records.

## Safety Notice

Incorrect ROM definitions can expose the wrong memory locations as maps or thresholds. Editing or flashing with a mismatched definition can cause drivability issues, fail-safe behavior, ECU damage, or a no-start condition.

Use this only with the matching `55570306` ROM unless every address, axis, scaling, and checksum behavior has been independently verified for another ROM ID.
